## 2. A1 — `fix(hooks): inspect plugin hooks without executing`

**Cambio**

- Añadir `discover_python_hooks(project_root)` que:
  - lee `plugin_hooks.py` si existe;
  - parsea con `ast.parse`;
  - devuelve nombres de `FunctionDef`/`AsyncFunctionDef` dentro de los hooks
    estándar (`pre_deploy`, `post_deploy`, `pre_package`, `post_package`,
    `pre_compile`, `post_compile`);
  - no importa ni ejecuta el módulo.
- `hooks list` usa el descubrimiento AST.
- `hooks test` y `deploy --trust` conservan `execute_python_hook`.
- Error de sintaxis: devolver lista vacía y warning, sin abortar.

**Tests**

- `plugin_hooks.py` que escribe `executed.marker`; `hooks list` no lo crea.
- Lista correcta con funciones normales y `async`.
- Sintaxis inválida no lanza.

**Aceptación**: listar un repo no confiable no ejecuta código.

## 3. A2 — `fix(deploy): skip nested target in dry-run`

**Cambio**

- En `plan_deploy`, importar/usar `_is_same_or_nested(item, target_path)` antes
  de descender o contar, igual que `sync_directory`.
- No contar el target ni sus archivos.
- Mantener el conteo de delete del destino.

**Tests**

- Proyecto con `target_path` dentro de `project_root`.
- Dry-run no cuenta archivos del target.
- Proyecto normal conserva conteos.

**Aceptación**: dry-run y deploy real describen el mismo conjunto.

## 4. A3 — `fix(compile): swap docs atomically`

**Cambio**

- Compilar en `build_dir` temporal.
- Si `help/html` existe, renombrarlo a `help/.html.backup-<pid>`.
- Mover `build_dir` a `help/html`.
- Si el move falla, restaurar el backup y devolver False.
- En éxito, borrar el backup.
- Si no había docs previos, limpiar staging en fallo.

**Tests**

- Fallo de `shutil.move` después de compilar: el `index.html` anterior sigue
  existiendo y con el mismo contenido.
- Éxito: reemplaza docs y no deja backups.

**Aceptación**: un fallo nunca destruye la documentación previa.

## 5. A4 — `fix(dclean): resolve absolute profiles`

**Cambio**

- Extraer `resolve_profile_dir(profile, qgis_version)` en `core/deploy.py`:
  - si `profile` es absoluto, usarlo como plugins dir;
  - si no, `get_qgis_plugin_dir(profile, version)`.
- Usarlo en `uninstall_plugin`, `deploy_plugin` (cuando `dest_dir is None`) y
  `dclean` (a través de `uninstall_plugin`).
- Validar que la ruta absoluta no sea el filesystem root y que el target sea
  hijo directo.
- No cambiar `profiles`, que lista perfiles por nombre.

**Tests**

- `uninstall_plugin(profile=<tmp>/plugins, qgis_version=4)` elimina
  `<tmp>/plugins/<slug>`.
- Perfil relativo sigue usando `get_qgis_plugin_dir`.
- Ruta insegura (`/`) se rechaza.

**Aceptación**: `deploy` y `dclean` interpretan igual `--profile`.

## 6. A5 — `fix(compile): serialize progress callbacks`

**Cambio**

- `_run_jobs` sigue paralelizando el trabajo, pero los eventos se emiten desde
  el hilo llamante.
- Opción simple: worker devuelve `(ok, events)` ya; `_run_jobs` recoge resultados
  y el hilo principal llama `_emit_result` en orden.
- Verificar que `CompileContext` no se comparte para emitir desde workers.
- El callback sigue recibiendo `START`/`PROGRESS`/`DONE` en orden determinista.

**Tests**

- `jobs=2`, callback registra `threading.get_ident()`: un solo hilo emisor.
- Todos los `START`/`DONE` presentes.
- Fallo de un worker no impide emitir los eventos de los demás.

**Aceptación**: `--jobs > 1` no corrompe el progress bar.

## 7. A6 — `fix(package): deterministic ZIP order`

**Cambio**

- Ordenar `_collect_zip_items` por `arcname` antes de escribir.
- Mantener `SOURCE_DATE_EPOCH` y permisos.
- No cambiar el contenido ni los nombres.

**Tests**

- Mismo proyecto, distinto orden de creación de archivos → mismo SHA256.
- ZIP contiene exactamente los mismos arcnames.

**Aceptación**: build reproducible byte a byte.

## 10. Riesgos

| Riesgo | Mitigación |
| :--- | :--- |
| `hooks list` cambia salida al no ejecutar | Mantener mismos nombres; test de listado |
| `plan_deploy` cambia conteos | Test comparativo dry-run/real |
| Swap de docs deja backups | Limpiar en éxito; test de éxito/fallo |
| Perfil absoluto elimina ruta incorrecta | Validar hijo directo y root; tests |
| Serialización reduce paralelismo | Mantener workers; solo serializar emisión |
| Orden ZIP rompe goldens | Actualizar una vez; test de reproducibilidad |

## 2. Commit 1 — `fix(manifest): preserve all deploy targets`

**Problem**: `_load()` keeps only the current target; `save()` writes
`{current_target: entries}`, deleting cache entries for other profiles/QGIS
versions.

**Change**:
- Add `self._all_targets: dict[str, dict]` from the loaded `targets`.
- `_load()` keeps the whole mapping, validating dictionary values.
- `save()` sets `self._all_targets[self._target_key] = self.entries` and writes
  the complete mapping.
- Preserve schema/version handling and atomic write.
- Do not trust arbitrary keys for filesystem operations; they remain JSON-only
  cache keys.

**Tests**:
- Deploy to target A, then target B; both keys remain after B saves.
- Re-open A and verify its entries are intact.
- Corrupt/unknown schema still falls back safely.

**Acceptance**: manifest never drops unrelated target entries.

## 3. Commit 2 — `fix(clean): prune virtualenvs and dependency dirs`

**Problem**: `rglob("__pycache__")`, `rglob("*.pyc")` and compiled-output scans
enter `.venv/`, `env/`, `libs/`, `.git/`, etc.

**Change**:
- Introduce a shared `_EXCLUDED_DIRS` set (reuse
  `_COMPILE_EXCLUDED_DIRS` or a cleanup-local equivalent):
  `.git`, `.venv`, `venv`, `env`, `libs`, `node_modules`, `build`, `dist`,
  `__pycache__`, test/tool caches.
- Replace `rglob` with `os.walk(topdown=True)` and prune `dirnames` in place.
- Apply the same pruning to:
  - cache directories (`__pycache__`, `.pytest_cache`, `.ruff_cache`);
  - bytecode/sidecars (`*.pyc`, `*.qpj`, `*.cpg`);
  - compiled `.ui`/`.qrc` outputs.
- Never follow symlinked directories.
- `--dry-run` and `--keep-generated` retain their current behavior.

**Tests**:
- `.venv/lib/.../__pycache__` and `.pyc` remain untouched.
- Project `__pycache__` and `.pyc` are removed.
- `libs` and `.git` are not traversed.
- Compiled `.ui/.qrc` behavior and dry-run unchanged.

**Acceptance**: clean never modifies a virtualenv/dependency tree.

## 4. Commit 3 — `fix(bump): support SemVer prerelease suffixes`

**Problem**: `parts = current.split(".")` and `map(int, parts)` fail for
`1.0.0-rc1` and `1.0.0.1`.

**Change**:
- Extract with `re.match(r"^(\d+)\.(\d+)\.(\d+)", current)`.
- Accept prerelease/build suffixes and ignore extra components after patch.
- Keep existing pad-for-missing-components behavior (`1.2` → `1.2.0` before
  bump).
- Preserve invalid-version error and exit code.

**Tests**:
- `1.0.0-rc1` + patch → `1.0.1`.
- `0.2.0-beta` + minor → `0.3.0`.
- `1.0.0.1` + patch → `1.0.1`.
- `1.2` + patch → `1.2.1`.
- Invalid `not.a.version` still exits 1.

**Acceptance**: no `ValueError: too many values to unpack`.

## 5. Commit 4 — `fix(validate): accept README and imported classFactory`

### M1 — README

- Accept `README` exactly or `README.<ext>`:
  ```python
  name == prefix or name.startswith(prefix + ".")
  ```
- Keep warning for missing README.

### M3 — classFactory

- Parse `__init__.py` with `ast.parse`.
- Accept:
  - `def classFactory(...)` / `async def classFactory(...)`;
  - `from .module import classFactory`;
  - `from .module import classFactory as ...` (alias still exports the name).
- If syntax parsing fails, fall back to a conservative regex for `def`/import.
- Keep the existing error only when the symbol is truly absent.
- Do not execute the file.

**Tests**:
- Literal `def classFactory`.
- Multiline annotated definition.
- `from .main import classFactory`.
- Malformed Python still falls back and reports/accepts appropriately.
- README exact, README.md, and missing README.

**Acceptance**: valid plugin patterns pass structure/artifact validation.

## 6. Commit 5 — `fix(compile): skip fresh .qrc outputs`

**Problem**: `_compile_single_qrc` always invokes RCC.

**Change**:
- Before compiling, compute `py_file = qrc.with_suffix(".py")`.
- If `_is_stale(qrc, py_file)` is false, skip the RCC call and emit the same
  `START`/`DONE` events.
- Keep temporary-output comparison/replace behavior for changed files.
- Preserve failure semantics and callback ordering.

**Tests**:
- Fresh `.py` → no `subprocess.run` call, events still emitted.
- Stale `.qrc` → compile and replace.
- Failed RCC preserves previous output.
- `jobs=2` ordering still stable.

**Acceptance**: no unnecessary RCC executions.

# Release v0.16.2 - Security and Correctness

**Released**: 2026-11-18

Closes the critical findings from the v0.16.1 code-smell review before the
0.17.0 structural refactor.

## Fixed

- **Hook inspection**: `hooks list` reads `plugin_hooks.py` with AST and never
  imports or executes it. `hooks test` and `deploy --trust` still execute hooks.
- **Deploy dry-run**: a destination nested inside the project is skipped, so
  dry-run copy counts match the real deployment.
- **Documentation swap**: the previous `help/html` is kept as a temporary backup
  and restored if moving the new build fails.
- **`dclean` absolute profiles**: `--profile /path/to/plugins` now resolves
  consistently with `deploy`; filesystem roots are rejected.
- **Compile progress**: parallel workers return events that are emitted from the
  calling thread, keeping progress deterministic with `--jobs > 1`.
- **Reproducible ZIP**: package members are written in sorted archive-name order.

## Compatibility

- No CLI syntax or exit-code changes.
- Runtime dependencies remain empty (stdlib only).
- Hook execution policy is unchanged: listing is inert; testing/deploying still
  requires explicit trust.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.16.2
```

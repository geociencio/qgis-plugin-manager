# Release v0.16.1 - Correctness Patch

**Released**: 2026-11-01

Fixes the confirmed correctness findings from the v0.15.1 code analysis.

## Fixed

- **Deploy manifest**: saving target B no longer deletes target A's cache
  entries. Multi-profile/QGIS deployments keep all targets.
- **Clean**: `.venv`, `venv`, `env`, `libs`, `.git`, `node_modules`, `build` and
  `dist` are pruned from recursive scans; project caches are still removed.
- **Bump**: `1.0.0-rc1`, `0.2.0-beta`, `1.0.0.1` and short versions are accepted.
- **Artifact validation**: a file named exactly `README` is accepted.
- **Structure validation**: imported, aliased and multiline `classFactory`
  definitions pass via AST, with a syntax-error regex fallback.
- **Compile**: fresh `.qrc` outputs are not recompiled; the progress label is
  `📚 Compiling`.

## Compatibility

- No CLI syntax or exit-code changes.
- Runtime dependencies remain empty (stdlib only).

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.16.1
```

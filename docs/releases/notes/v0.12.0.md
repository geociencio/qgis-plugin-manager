# Release v0.12.0 - JSON, explainability and safe defaults

**Released**: 2026-10-25

Platform/UX release closing the P2 backlog.

## Added

- `--json` for `validate`, `analyze` and `package` (versioned schema on stdout).
- `ignore check <path>` with `--explain` for nested/negated rules.
- `deploy --dry-run` showing copy/delete/backup/purge/hook actions without writes.
- `profiles list` showing profile paths and plugin counts.
- `package --require-docs` to block packages without `help/html/index.html`.
- `analyze --max-cc N` passthrough.

## Breaking change

- **Hooks no longer use a shell by default.** `HookPolicy.shell` is now `False`.
  Commands that rely on shell syntax must opt in with
  `HookPolicy(shell=True)`; otherwise they fail with a migration error instead
  of being interpolated by `/bin/sh`.

## Compatibility

- JSON output uses exit codes 0/1 and leaves progress/log output on stderr.
- `deploy --dry-run`, `profiles list` and `ignore check` are read-only.
- Existing argv-style hooks (`python script.py`, `touch file`) continue to work.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.12.0
```

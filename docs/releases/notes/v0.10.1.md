# Release v0.10.1 - Deploy, compile and release-safety fixes

**Released**: 2026-10-25

Patch release for the P0 findings in the qgis-manage 0.10.0 analysis.

## Fixed

- **Consecutive deploys**: backup names now use microsecond precision and a
  collision-safe suffix, so two deploys in the same second do not fail with
  `File exists`.
- **Repeatable compile types**: `--type resources --type translations`
  compiles both families. Previously argparse kept only the last value, leaving
  resources silently stale.
- **Version consistency**: `package --release-version` fails when the requested
  version differs from `metadata.txt` unless `--stamp` or a matching
  `--sync-version` makes them agree. ZIP filename and portal metadata can no
  longer diverge.
- **Non-interactive purge**: `deploy --purge-backups --yes` works in CI and
  scripts. `--yes` also applies to missing-directory and deploy confirmations;
  it cannot be combined with `--interactive`.
- **Safe clean**: `clean --dry-run` previews without deleting,
  `--keep-generated` preserves `.py` files generated from `.ui`/`.qrc`, and a
  warning is emitted when such a file is tracked by Git.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.10.1
```

No API changes beyond the new flags. The default deploy and clean behavior is
unchanged when the new options are not used.

# Release v0.13.0 - Built-artifact validation

**Released**: 2026-10-25

Closes the qgis-manage P0 item from the upstream gate integration design.

## Added

- `validate --zip PATH` validates a built ZIP without reading the source tree.
- Stable artifact checks: `ARTIFACT_ROOT`, `ARTIFACT_METADATA`,
  `ARTIFACT_LICENSE`, `ARTIFACT_SIZE`, `ARTIFACT_BINARY`, `ARTIFACT_DEV_FILE`,
  `ARTIFACT_PERMISSIONS`, `ARTIFACT_ICON`, `ARTIFACT_README`.
- `validate --zip --json` emits the versioned envelope with all checks.
- `validate --zip --strict-permissions` upgrades non-portal modes to errors.
- `package --repo-check` audits the built ZIP after writing it.
- Packaging normalizes modes to `0644`/`0755` and uses deterministic timestamps
  when `--repo-check` is active.

## Fixed

- The artifact size gate is **25 MB over the ZIP**, not over the project
  directory.
- `--repo-check` no longer trusts the source tree alone; an invalid built ZIP
  fails the command.

## Compatibility

- An invalid ZIP is kept for diagnosis; the command returns `1`.
- Invalid/missing ZIP input returns `2` from `validate --zip`.
- Icon and README findings are warnings unless the artifact is otherwise invalid.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.13.0
```

# Release v0.17.0 - Structural Refactor

**Released**: 2026-11-18

This release completes the B1-B7 structural refactor from the manual code-smell
review. CLI behavior and exit codes are unchanged; the internals are now smaller,
more deterministic and easier to test.

## Changed

- **One path policy**: `PathPolicy` and `ProjectWalker` replace five independent
  tree walkers in compile, package, clean, repository validation and discovery.
  Dev/tool exclusions remain root-only, so nested `gui/tools` is preserved.
- **Deploy workflow**: `DeployRequest`, `DeployPlan`, `DeployResult` and
  `DeployWorkflow` separate preparation/execution from `DeployCommand`.
  `execute` is 29 lines and purge asks for confirmation once.
- **Package workflow**: `PackageRequest`, `PackageResult` and `PackageWorkflow`
  unify the package call. `--json` emits an envelope for every failure path.
- **CLI internals**: removed the `console as click` alias, added `CliError` with
  stable exit codes, `--debug` tracebacks, and project-root error mapping.
- **TOML**: version updates are atomic and preserve single or double quotes.
- **Security**: dependencies are PEP 508-validated, `--target` is confined to the
  project, templates are whitelisted, ZIP member/total reads are bounded, and the
  analyzer has a timeout and cached availability probe.

## Compatibility

- Runtime dependencies remain empty (stdlib only).
- Existing commands, flags, output and exit codes are preserved.
- `hooks test`/`deploy --trust` still execute hooks; `hooks list` remains inert.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.17.0
```

# Release Notes - qgis-manage v0.9.2 - Cross-platform CI fix

This is a patch release for **qgis-manage v0.9.2**. It contains no runtime
changes to the CLI; it restores a fully green CI across all supported platforms.

## 🐛 Fixed

- **Cross-platform tests**: the project discovery and native-hooks tests now pass
  on macOS and Windows.
  - `find_project_root` results are compared against the resolved temporary path
    (macOS exposes `/private/var/...`, and Windows uses 8.3 short names such as
    `RUNNER~1`).
  - The generated `plugin_hooks.py` is read with an explicit UTF-8 encoding,
    avoiding a `cp1252` `UnicodeDecodeError` on Windows.

CI is green on the full matrix: Ubuntu, Windows and macOS on Python 3.11, 3.12
and 3.13.

## 📦 Installation

```bash
uv tool install qgis-manage@latest
# or
pip install --upgrade qgis-manage
```

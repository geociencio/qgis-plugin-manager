# Release Notes - qgis-manage v0.9.1 - Packaging Housekeeping

This is a maintenance release for **qgis-manage v0.9.1**. It ships no new CLI
features; it focuses on code maintainability, release automation and documentation.

## 🧹 Maintainability

### Cohesive core package
The former 840-line `core.py` monolith was split into a focused package
(`qgis_manager.core`) with `platform`, `deploy`, `compile`, `package`, `cleanup`
and `scaffold` modules. The public API is preserved, so existing imports keep
working. Cyclomatic complexity was reduced across the board (no function exceeds
CC 10); the average dropped from **B (7.67)** to **A (4.44)**.

### Higher, enforced test coverage
CI now enforces a **80 % coverage floor** and runs `ruff format --check` in
addition to lint and type checks.

## 🤖 Release automation

- New `.github/workflows/release.yml`:
  - pushing a `vX.Y.Z` tag creates a **draft** GitHub Release;
  - publishing that release builds the distribution and uploads it to **PyPI**.
- Release documentation was reorganized under `docs/releases/` (`notes/` for the
  release notes, `github/` for GitHub release bodies).

## 🧩 Agent tooling

The project now consumes the **agentic-forge** framework as a git submodule
(`.agent/`), with project-owned state isolated under `.agent-state/`.

## 📦 Installation

```bash
uv tool install qgis-manage@latest
# or
pip install --upgrade qgis-manage
```

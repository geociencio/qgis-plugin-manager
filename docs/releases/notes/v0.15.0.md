# Release v0.15.0 - Portal security

**Released**: 2026-10-25

Connects qgis-manage to qgis-plugin-analyzer 1.18 and adds the portal security
orchestration.

## Added

- `security --portal` runs native rules plus Bandit, detect-secrets and Flake8.
- `--exclude PATTERN` (repeatable) scopes the analyzer scan.
- `security --json` wraps the analyzer report in the manager envelope
  (`data.analyzer`).
- `--fail-on critical|warning|info|none` for the portal gate.

## Changed

- Minimum `qgis-plugin-analyzer` is **1.18.0**, which adds ignore-file support,
  `--exclude`, `--scope`, `--tools` and JSON security reports.

## Compatibility

- `security` without `--portal` keeps its previous behavior.
- Missing optional analyzer tools exit `2`; invalid analyzer JSON exits `2`.
- Install analyzer extras with `qgis-plugin-analyzer[portal]` for Bandit,
  detect-secrets and Flake8.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.15.0
```

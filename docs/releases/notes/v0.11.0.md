# Release v0.11.0 - Faster deploys, scans and compiles

**Released**: 2026-10-25

Performance release for the P1 findings in the qgis-manage 0.10.0 analysis.

## Highlights

- **Deploy manifest**: unchanged files are skipped using cached SHA256/size/mtime
  fingerprints stored under `.qgis-manage/deploy-manifest.json`. Use
  `deploy --no-manifest` for a full content scan.
- **Reflink backups**: Linux backups use `cp --reflink=auto` when supported,
  falling back to a normal copy.
- **Pruned repository scan**: `package --repo-check` walks once and prunes
  ignored/symlinked directories before checking for prohibited binaries.
- **Compile freshness**: fresh `.qm` translations are skipped; UI/QRC compile to
  a temporary file and only replace the output when bytes change.

## Compatibility

- Default behavior is unchanged when the manifest is enabled; `--no-manifest`
  forces the previous full-scan path.
- Backups remain complete copies; reflink is an optimization, not a hardlink.
- Failed compiles still preserve the previous output.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.11.0
```

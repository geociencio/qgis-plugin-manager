# Release v0.15.1 - Tool-only distributions

**Released**: 2026-10-31

Packaging fix for the 0.15.0 source distribution.

## Fixed

- The sdist is restricted to:
  - `src/qgis_manager/**`
  - `README.md`
  - `CHANGELOG.md`
  - `LICENSE`
  - `pyproject.toml`
  - standard packaging metadata (`.gitignore`, `PKG-INFO`)
- Removed `.agent-state/`, `help/`, `docs/`, `tests/`, `scripts/`, `scaffold/`
  and analysis artifacts from the sdist.
- Added `scripts/check_distribution.py`; the release workflow now rejects any
  wheel/sdist that contains non-tool files before `uv publish`.

The wheel was already clean; this release fixes the source archive and adds a
regression guard.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.15.1
```

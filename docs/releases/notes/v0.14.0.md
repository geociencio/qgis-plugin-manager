# Release v0.14.0 - Configurable artifact gates

**Released**: 2026-10-25

Extends the 0.13.0 artifact layer with project configuration, QGIS 4 guidance
and reproducible ZIP timestamps.

## Added

- Project settings in `[tool.qgis-manager]`:
  - `docs_entry` (supports globs);
  - `max_package_size_mb`;
  - `icon_min_px`;
  - `normalize_permissions`.
- `ARTIFACT_QGIS4` warnings for missing/old `qgisMaximumVersion` and
  deprecated `supportsQt6`.
- `ARTIFACT_CONFIG` info when `.bandit`, `.flake8` or `.secrets.baseline` is
  packaged.
- `validate --zip --max-size-mb` and `--icon-min-px`.
- `SOURCE_DATE_EPOCH` support for normalized ZIP timestamps.

## Changed

- `package --require-docs` now uses the configured `docs_entry`, including
  globs such as `help/html/*/index.html`.
- `package` honors `normalize_permissions=true` even without `--repo-check`.

## Compatibility

- Defaults remain 25 MB, 32 px, `help/html/index.html`, and normalization on
  `--repo-check`.
- Artifact icon/README/QGIS4 findings are warnings; blocking errors still exit 1.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.14.0
```

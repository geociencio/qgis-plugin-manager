# Release v0.10.0 - Safety, trust and platform hardening

**Released**: 2026-10-25

This release is a significant hardening and platform milestone after v0.9.2. It
makes lifecycle operations safer, closes the P0-P3 quality backlogs and adds
opt-in platform controls while keeping the default CLI behavior stable.

## 🚀 Highlights

- **Safer deploy/package**: validated ASCII slugs, symlink confinement, POSIX ZIP
  names, atomic metadata updates and content-based deploy comparison.
- **Explicit trust**: hooks and dependency installation require `--trust`.
- **Strict typing**: the package ships `py.typed` and passes `mypy --strict`.
- **Better platform behavior**: nested ignore files, XDG/APPDATA config,
  bounded tool execution, `compile --jobs` and external command entry points.
- **Quality**: 269 tests, 91.03 % combined coverage, branch gate 90 %, C901 = 0.

## ⚠️ Behavior changes

- `deploy` skips project hooks and `package` refuses to install declared
  dependencies unless `--trust` is passed. Add `--trust` to existing automation
  that relies on these features.
- `--purge-backups` now honors an absolute `--profile` directory and removes
  matching backups for real.
- `deploy` skips symlinked sources and refuses a symlinked plugin destination.
- ZIP member names always use `/`, including on Windows.
- `compile --jobs N` is available; the default remains `--jobs 1`, so output and
  callback ordering are unchanged unless you opt in.
- Nested `.qgisignore`/`.gitignore` files now apply to their subtree; `!pattern`
  re-includes a path. `.git/info/exclude` is not supported.
- Config is read from `XDG_CONFIG_HOME`/`APPDATA` with the previous home-based
  path as fallback.
- External commands can be provided through the `qgis_manager.commands`
  entry-point group; built-in command names cannot be overridden.

## 🛠️ Fixes and improvements

- Preserve comments, custom sections and multiline values in `metadata.txt`.
- Generate valid Python class/module names and valid template metadata.
- Propagate UI/QRC/TS/documentation compile failures and keep previous docs.
- Patch PyQt6 imports to `qgis.PyQt`.
- Respect the configured profile and CLI overrides.
- Require `about`/`repository` in official repository checks.
- Reject unsafe package versions (`/`, `\`, empty, `..`).
- Compare file content when size/mtime match, avoiding stale deploys.
- Bound Sphinx/pyuic/rcc/lrelease execution to 300 seconds.
- Add configurable timeouts and `--dry-run` to dependency installation.
- Centralize command errors and instantiate CLI commands once.
- Split validation/metadata modules and test suites for maintainability.

## 📦 Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.10.0
```

No new runtime dependencies were introduced. Projects using hooks or dependency
installation must add `--trust` to their automated commands.

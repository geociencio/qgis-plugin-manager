# Release v0.16.0 - Zero runtime dependencies

**Released**: 2026-11-01

qgis-manage now runs on the Python standard library alone.

## Changed

- **Runtime dependency removed**: `click` is no longer a dependency;
  `project.dependencies` is empty.
- **Internal console adapter**: output, ANSI styling, confirmations, prompts and
  progress bars are implemented in `qgis_manager.cli.console` using stdlib only.
- **Policy enforcement**: `tests/test_dependency_policy.py` asserts an empty
  runtime dependency list and rejects third-party imports under
  `src/qgis_manager`.
- **Distribution metadata**: built wheels declare no runtime `Requires-Dist`.

## Compatibility

- CLI output, prompts, progress and exit codes are preserved.
- The adapter honors `NO_COLOR` and `TERM=dumb`; color is only emitted on a TTY.
- Dev dependencies (pytest, ruff, mypy, analyzer) remain optional extras.

## Upgrade

```bash
uv tool install --upgrade qgis-manage
# or
uv add --dev qgis-manage@0.16.0
```

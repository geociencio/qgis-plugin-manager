# v0.6.0: The Council of Sages – Advanced Automation

This release introduces robust project management features for QGIS plugin developers.

### Highlights
- 🛡️ **.qgisignore**: Full support for gitignore-style exclusions.
- 📦 **install-deps**: Automatic management of third-party libraries into local `libs/`.
- 🏗️ **Smart Scaffolding**: Template-based initialization with `--template`.
- 🐍 **Python Hooks**: Native script execution with project context.
- 🔍 **Unified Analyze**: Integrated quality checks via `qgis-manage analyze`.

See [v0.6.0.md](../notes/v0.6.0.md) for full details.

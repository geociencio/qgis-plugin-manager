# Memory Policy — qgis-plugin-manager

This project uses the Agentic Forge 3-tier memory model. The framework lives in
`.agent/` (submodule); **all project-owned state lives in `.agent-state/`** and must
never be written into the framework.

## Tiers

| Tier | Location | Lifetime | Purpose |
| :--- | :--- | :--- | :--- |
| Working | `AI_CONTEXT.md`, `.agent-state/task.md`, `.agent-state/next_steps.md` | Current session/phase | Active context, task board and handover |
| Episodic | `docs/maintenance/`, `.agent-state/history/` | 90 days for snapshots | Session logs, archived task boards and next_steps snapshots |
| Semantic | `.agent-state/memory/AGENT_LESSONS.md`, `.agent/skills/*/SKILL.md`, `.agent-state/skills/*/SKILL.md` | Long-lived | Distilled lessons and procedures |

## Rules

1. **Single source of truth for metrics**:
   `.agent-state/memory/agent_metrics.json`, generated by
   `uv run python scripts/sync_metrics.py`. Never hand-edit metric values in
   documentation without refreshing the metrics file first.
2. **Lessons are promoted, not duplicated**: a lesson that is fully reflected in a
   `SKILL.md` must set `consolidated_in: <skill>` and can then be pruned.
3. **Pruning is opt-in**: `python .agent/tools/forge.py memory prune` is a dry-run.
   Use `--apply` to rewrite lessons and delete snapshots older than 90 days.
4. **Session closure**: every non-trivial session appends a report under
   `docs/maintenance/`, updates `.agent-state/next_steps.md`, and rotates
   `last_session` with `forge.py metrics close-session --topic <name>`.
5. **No secrets or machine-specific paths** in lessons or skills.
6. **Language**: documentation, lessons and commit messages are written in English.

## Promotion checklist

- [ ] The lesson describes a repeatable rule, not a one-off incident.
- [ ] It is reflected in the relevant `SKILL.md` (or a workflow decision).
- [ ] `consolidated_in` points to the exact skill name.
- [ ] The stale duplicate is removed from the active lessons block after review.

# qgis-manage profiles

```text
qgis-manage profiles v0.13.0
List QGIS profiles and plugin counts

Usage: qgis-manage profiles [-h] [--qgis-version QGIS_VERSION] ACTION ...

Arguments:
  ACTION
    list                List profiles

Options:
  -h, --help            show this help message and exit
  --qgis-version QGIS_VERSION
                        Major QGIS version (default: 3)

Examples:
    # List profiles for QGIS 3
    qgis-manage profiles list
```
